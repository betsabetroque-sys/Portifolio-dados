# 01 · Diagnóstico de produto com SQL (Olist)

## 1. Contexto do produto
Marketplace brasileiro de e-commerce. O time de produto quer entender onde perde clientes e o que afeta a satisfação.

## 2. Perguntas de negócio
- Qual a evolução de pedidos por mês?
- Onde o funil de compra perde mais pedidos?
- Qual a retenção por coorte mensal?
- O atraso na entrega reduz a nota de avaliação?

## 3. Dados
[Brazilian E-Commerce Public Dataset by Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). Baixe e coloque em `data/raw/`.
